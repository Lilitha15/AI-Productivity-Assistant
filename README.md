# Dream Design AI Studio

Build a Fashion Business AI Productivity Assistant Website

Create a modern, elegant, responsive website for a fashion-design business called Dream Design Create Build — Fashion Business AI Assistant.

1. Project purpose

Build an AI-powered productivity assistant that helps fashion designers and small fashion-business owners save time, organize their work, communicate professionally, research fashion trends, and manage daily business activities.

The website must demonstrate the CAPACITI AI Skill Accelerator Programme project requirements by providing practical AI tools, effective prompt engineering, measurable productivity benefits, and responsible AI safeguards.

Target users include independent fashion designers, clothing entrepreneurs, boutique owners, fashion students, and small creative businesses.

2. Design and visual identity

Use the attached fashion designer studio image as the main visual inspiration and hero image.

Create a luxurious, professional fashion-studio aesthetic with:

Black, cream, warm beige, blush pink, and subtle gold accents.

Elegant typography combining a sophisticated serif heading font with a clean sans-serif body font.

Generous white space, refined cards, subtle shadows, rounded corners, and tasteful animations.

Fashion mood boards, garment sketches, fabric swatches, sewing measurements, and clothing-rack imagery.

A premium editorial layout inspired by a luxury fashion studio.

Responsive layouts for desktop, tablet, and mobile.

Use the brand message: “Dream. Design. Create. Build.”

The website must look like a real, usable business productivity application, not just a static landing page.
